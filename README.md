# Bioinfo Pipeline

## Project Description
This project simulates a bioinformatics pipeline for RNA sequencing data analysis. 
It includes steps for quality control, filtering and basic variant analysis.

---

## Dependencies
The following tools and packages are required:

- Python 3.14
- (Optional) R 4.0+
- Git

---

## Installation Instructions for dependencies
Install Python 3.14 from https://www.python.org
Verify the installation by running:
python --version

Install R from https://posit.co/download/rstudio-desktop/
Verify the installation 
R --version
